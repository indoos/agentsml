Standard Architecture

AgentsML Specification v0.2

AgentsML is a declarative, IR-first markup language that models AI agents, tools, workflows, policies, and multi-agent protocols as a single portable specification.

1. Portable IR Model

Single Intermediate Representation decouples agent logic from target framework idioms and vendor lock-in.

2. Deterministic Verification

Rigorous 3-tier certification (External-Runtime, Offline-Behavioral, Structural) verified against real SDKs.

3. Protocol Native

Built-in protocol first-class citizens for Model Context Protocol (MCP), Agent-to-Agent (A2A), and AG-UI streaming.

📦 Core Object Model

  • AgentSystem: Top-level document containing metadata, profiles, models, agents, tools, and workflows.
  • model: Model declaration with provider (openai, google, anthropic), name, and parameters.
  • agent: Autonomous actor with model, instructions, assigned tools, and output schema.
  • tool: Function/operation with schema, permissions, and side-effect contracts (read, write, payment).
  • workflow: Execution graph composed of steps and edges with conditional routing.
  • step: Invocation node (agent, tool, approval, or a2a_agent) with optional join: wait_all.
  • edge: Directed connection between steps with boolean condition grammar.

⚡ Normative Condition Grammar

Edge conditions and step expressions are evaluated deterministically using standard syntax without arbitrary code execution:

${steps.assess.output.decision == "approved"}
${state.risk_score > 0.08 || state.is_vip == false}
${steps.verify.output.status != "declined"}
  • Comparisons: ==, !=, <, <=, >, >=
  • Boolean operators: &&, ||, !
  • Reference roots: input, state, steps.<step_id>.output

Reference Compiler & CLI Guide

The reference compiler is packaged in agentsml-impl and exposes the unified agentsml CLI. Install via pip:

pip install agentsml-impl

⚡ agentsml compile

Compile an AgentsML document to target-specific agent code.

agentsml compile agent.yaml -t langgraph -o ./build

📊 agentsml graph

Render execution graphs as Mermaid flowcharts or ASCII DAGs.

agentsml graph agent.yaml --format mermaid
agentsml graph agent.yaml --format ascii

▶️ agentsml run

Compile and execute against target runtimes directly.

agentsml run agent.yaml -t google-adk -q "Analyze portfolio"

🛡️ agentsml validate

Schema and semantic validation with diagnostic reports.

agentsml validate agent.yaml
